# 情缘杯 v2 功能徽章

本目录存放选手端 v2 的九枚主功能徽章。文件均为 `418 × 418` 透明 PNG，外围深绛红画布已移除，圆形徽章自身的纸纹底与金属边框需要保留。

| 文件 | 业务语义 | 建议使用位置 |
| --- | --- | --- |
| `lover.png` | 情缘报名单元 | 报名类型选择、情缘资料卡、队伍中的情缘核心位 |
| `mate.png` | 搭子报名单元 | 报名类型选择、搭子大厅、搭子成员位 |
| `solo.png` | 独狼报名单元 | 报名类型选择、独狼候选池、独狼成员位 |
| `invitation.png` | 邀请与待处理邀请 | 搭子邀请、组队邀请入口和邀请空状态 |
| `team.png` | 五人最终队伍 | 队伍总览、组队完成状态、成员构成区域标题 |
| `solo-draw.png` | 独狼盲盒抽取 | 抽取入口、待抽取空状态、运营代抽结果提示 |
| `schedule.png` | 赛程与对阵树 | 赛程页入口、阶段导航空状态、赛事进程卡片 |
| `match-config.png` | 单场心法/配装填写 | 对局详情里的赛前配置入口与待填写提示 |
| `destiny-card.png` | 天命签 | 单场天命签抽取入口、未抽取状态和结果展示 |

## 前端使用约束

- 这是插画级功能徽章，建议显示尺寸为 `64–144px`；不要用于 `16–24px` 的行内操作按钮。
- 页面背景由 CSS 或容器组件负责，图片本身不要再补色块；暗色背景上可以加轻微金色外发光。
- 审核中、已通过、已拒绝、已锁定、已淘汰等通用状态，继续使用项目图标库、SVG 或 CSS 色彩表达，不再从这套徽章派生。
- 后续如需压缩，可由构建链生成透明 WebP；PNG 保留为设计源文件。
- 不建议把这些 PNG 自动描摹成 SVG：纹理、渐变和细小金属装饰会转成大量路径，难维护且通常不会更小。若要 SVG，应另画一套简化的单色线性版本。
