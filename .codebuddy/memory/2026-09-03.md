# 2026-09-03

## mid_autumn 活动 App 内嵌改造（进行中）
- 为 `src/pages/event/mid_autumn` 增加 App 内嵌环境支持：新增 `src/utils/env.js`（`isApp`/`applyAppEnv`，供 event 下多活动复用）、`Index_App.vue`、`Detail_App.vue`（仍是空壳，`components_app/` 目录为空），入口 `index.js` 按 `isApp()` 切换根组件并调用 `applyAppEnv()`。
- 修复 Vue Router 报错：`router.js` 中 `Detail`/`Info` 误写为 `const X = import(...)`（直接赋 Promise），已改为 `() => import(...)`。报错特征：`Component "default" in record with path "..." is a Promise ...`。
- 已知点：桌面诗词分享链接 `#/2026/poem`、`#/2026/poem/detail` 在 `isApp()` 为真时无路由匹配（no match 警告），App 分支现仅 `/` 与 `/info`；若 App 需承载诗词详情需自行补 poem 路由。注意 `isApp()` 读 `localStorage.__env==="app"`，调试残留会导致桌面也被当作 App 环境。
- 修复 App 端点菜单跳 `/info` 页面不显示：根因是 App 环境根组件 `Index_App.vue`（index.js 里 createApp 按 isApp() 切换）模板没有 `<router-view>`，路由匹配后无处渲染。方案：① Index_App 模板内加 `<router-view :years="years">` 作子页面出口；② router.js 的 App 分支中 `/` 用空组件 `{ render: () => null }` 占位（首页内容/菜单由根组件承担，避免 router-view 把 Index_App 再渲染一份造成双重渲染）。App 内嵌采用「背景+底部菜单常驻根组件、子页面填充 router-view」架构，页面迁移不必要；已给 Detail_App.vue 加了最小占位（year/tab 从 `$route.query` 读），待用户填充真实内容。另注意：hash 路由 push 的 `query.__env="app"` 不会进 `location.search`，对 `isApp()` 无效（无害但冗余）。
